## 1. LLM 모델 비교·선정 보고서

### 1.1 개요
* **타겟 업무 과업**: 유튜브 키워드 입력 기반 영상 기획, 대본 구성, CTR 극대화 썸네일/제목 자동 추천
* **비교 대상 모델**: OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, Google Gemini 1.5 Pro

### 1.2 모델별 평가 및 비교표 (요소 1: 모델 비교 보고서)

| 평가 항목 | 평가 기준 | GPT-4o | Claude 3.5 Sonnet | Gemini 1.5 Pro |
| :--- | :--- | :---: | :---: | :---: |
| **창의성 및 톤앤매너** | 한국어 유튜브 특유의 후킹(Hooking)과 자연스러운 구어체 구현 | ★★★★☆ | ★★★★★ | ★★★★☆ |
| **지시사항 준수율** | 대본 분량, 제약 조건(글자 수, XML 태그 사용) 엄격 준수 | ★★★★★ | ★★★★★ | ★★★★☆ |
| **환각(Hallucination)** | 존재하지 않는 툴 기능이나 허위 정보 생성 여부 | ★★★★☆ | ★★★★★ | ★★★★☆ |
| **장문 맥락 유지력** | 10턴 이상 멀티턴 대화 시 앞선 기획 맥락 유지 능력 | ★★★★☆ | ★★★★★ | ★★★★★ |

### 1.3 최종 선정 결론
* **최종 선정 모델**: **Claude 3.5 Sonnet**
* **선정 근거**: 한국어 구어체 대본 작성이 가장 자연스러우며, 10턴 이상의 대화 세션 중에도 초기 설정한 작가 페르소나 및 환각 통제 가이드라인을 가장 안정적으로 유지함.
