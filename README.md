# 🎬 YouTube Content Generation Prompt Package

LLM을 활용하여 유튜브 콘텐츠 제작 과정을 자동화하기 위한 Prompt Engineering 프로젝트입니다.

## 프로젝트 목표

입력한 키워드를 기반으로

- 영상 주제 기획
- 대본 작성
- 제목 추천
- 썸네일 문구 생성

을 자동 수행하도록 설계하였습니다.

## 대상 사용자

- 유튜브 채널 운영자
- 콘텐츠 제작자
- 마케팅 담당자
- AI Prompt Engineer

---

## 프로젝트 구성

1. LLM 모델 비교 보고서
2. 시스템 설계
3. Few-shot Prompt
4. Hallucination 검증
5. 실제 10Turn 대화
6. Prompt 개선 이력
7. 운영 정책
8. 비용 절감 전략
