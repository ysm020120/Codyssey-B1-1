## 1. LLM 모델 비교·선정 보고서

### 1.1 비교 목적
* **목적**: 유튜브 채널 운영 중 '기획안 및 영상 대본(스크립트) 작성' 과업에서 몰입감 있는 스토리텔링, 채널 페르소나 유지, 구성안 준수 능력을 갖춘 최적의 LLM을 선정하기 위함.
* **평가 목적 과업**: 산발적인 주제 메모와 핵심 메시지를 바탕으로 유튜브 기획안(제목 후보, 썸네일 카피, 오프닝 Hook, 본문 3단 구성, CTA)을 정형화된 양식으로 작성.

### 1.2 비교에 사용한 동일 입력 (테스트 프롬프트)
```text
[과업] 아래 아이디어 메모를 바탕으로 '유튜브 지식 정보형 영상 기획안 및 오프닝 대본'을 작성하라.
[원문] "주제: AI 때문에 사라질 직업 vs 살아남을 직업. 요즘 단순 디자이너나 초급 개발자는 AI 때문에 위험하다는 말이 많음. 반면 현장직이나 인간의 감정을 다루는 직업은 안전하다고 함. 하지만 진짜 핵심은 'AI를 도구로 쓰는 사람'이 안 쓰는 사람을 대체한다는 것임. 시청자가 공포심만 느끼지 않고 마지막엔 희망을 갖게 해야 함."
[요구사항] 
1. 클릭을 유도하는 썸네일 카피 2가지 및 영상 제목 3가지 
2. 시청자를 몰입시킬 오프닝 Hook 대본 (30초 분량) 
3. 본문 3단계 구성안 (요약 불릿) 
4. 자극적인 찌라시성 내용 포함 금지 (근거 없는 통계 수치 언급 시 '확인 필요' 표기)
