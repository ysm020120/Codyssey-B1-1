## 1. LLM 모델 비교·선정 보고서

### 1.1 개요
* **타겟 업무 과업**: 유튜브 키워드 입력 기반 영상 기획, 대본 구성, CTR 극대화 썸네일/제목 자동 추천
* **비교 대상 모델**: OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, Google Gemini 1.5 Pro

### 1.2 모델별 평가 및 비교표 (요소 1: 모델 비교 보고서)

| 평가 항목 | 평가 기준 | GPT-4o | Claude 3.5 Sonnet | Gemini 1.5 Pro |
| :--- | :--- | :---: | :---: | :---: |
| **창의성 및 톤앤매너** | 한국어 유튜브 특유의 후킹(Hooking)과 자연스러운 구어체 구현 | ★★★★☆ | ★★★★★ | ★★★★☆ |
| **지시사항 준수율** | 대본 분량, 제약 조건(글자 수, XML 태그 사용) 엄격 준수 | ★★★★★ | ★★★★★ | ★★★★☆ |
| **환각(Hallucination)** | 존재하지 않는 툴 기능이나 허위 정보 생성 여부 | ★★★★☆ | ★★★★★ | ★★★★☆ |
| **장문 맥락 유지력** | 10턴 이상 멀티턴 대화 시 앞선 기획 맥락 유지 능력 | ★★★★☆ | ★★★★★ | ★★★★★ |

### 1.3 최종 선정 결론
* **최종 선정 모델**: **Claude 3.5 Sonnet**
* **선정 근거**: 한국어 구어체 대본 작성이 가장 자연스러우며, 10턴 이상의 대화 세션 중에도 초기 설정한 작가 페르소나 및 환각 통제 가이드라인을 가장 안정적으로 유지함.

## 2. 시스템 설계 문서

### 2.1 업무 과업 입력 템플릿 (요소 2: 업무 과업 입력 템플릿)
```markdown
[입력 템플릿]
- 영상 주제/키워드: {주제 입력}
- 타겟 시청자: {주요 타겟층}
- 영상 목표 길이: {예: 10분}
- 강조하고 싶은 메인 메시지: {핵심 내용 1~2개}
[System Prompt]
당신은 구독자 100만 명 지식 채널의 베테랑 메인 작가입니다.
시청자 체류 시간(Retention)과 클릭률(CTR)을 최우선으로 고려하여 답변을 구성합니다.
### [Few-Shot Example 1: 공부법 주제]
- Input: "공부 집중력이 안 나와서 고민인 학생 대상 영상 만들어줘."
- Output:
<hook>
"혹시 독서실 앉아서 30분 만에 핸드폰 보시나요? [화면 연출: 핸드폰 숏폼 스크롤하는 장면] 여러분 의지 문제가 아닙니다. 뇌를 속이는 이 '3분 법칙'만 알면 오늘부터 몰입 모드 들어갑니다."
</hook>
<thumbnail>
1. 3분 만에 몰입
2. 의지 문제 아님
3. 집중력 3배 상승
</thumbnail>

### [Few-Shot Example 2: 재테크 주제]
- Input: "사회초년생을 위한 월급 관리법 대본 짜줘."
- Output:
<hook>
"월급 통장에 돈 들어오자마자 스쳐 지나가시죠? [화면 연출: 통장 잔고 0원 줌인] 아직도 통장 하나로 다 관리해서 그렇습니다. 딱 4개로 쪼개는 순서 알려드릴게요."
</hook>
<thumbnail>
1. 통장 쪼개기
2. 월급 스쳐갈 때
3. 4개만 만드세요
</thumbnail>
