# Sample Input

## 프로젝트 테스트 입력

사용자가 LLM 시스템에 전달하는 예시 입력이다.

---

## 영상 정보


영상 주제:
ChatGPT를 활용한 업무 자동화 방법

타겟 시청자:
AI 활용에 관심 있는 20~40대 직장인

영상 길이:
10분

핵심 메시지:
AI 도구를 활용하면 반복 업무를 줄이고 업무 효율을 높일 수 있다.

원하는 톤:
친근하고 이해하기 쉬운 설명 방식


---

## 요청 Prompt


위 정보를 기반으로

영상 기획안
유튜브 제목
영상 대본
썸네일 문구

를 생성해주세요.


---

## 예상 목적

이 입력을 통해 다음 기능을 테스트한다.

- 콘텐츠 기획 생성
- 대본 생성
- 제목 생성
- 썸네일 생성
- 출력 형식 검증
