# 4. 문제 발견 및 개선

## 발견 문제

초기 테스트에서는 다음 문제가 발생하였다.

- 과도한 확정 표현 사용
- 근거 없는 숫자 생성 가능성
- 출력 형식 불일치

---

## 개선 방법

문제 해결을 위해 다음 요소를 추가하였다.

### System Prompt 개선

- 역할 정의 추가
- 출력 형식 지정
- 사실 검증 규칙 추가

### Few-shot Example 적용

- 원하는 출력 형태 제공
- 다양한 입력 상황 테스트

### Validation Process 적용

- 사실 확인
- 숫자 검증
- 표현 강도 검토
