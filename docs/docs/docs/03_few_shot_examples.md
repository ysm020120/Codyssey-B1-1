# 3. Few-shot Prompt 예시

## 3.1 개요

Few-shot Prompt는 LLM에게 입력과 출력의 예시를 함께 제공하여 일관된 품질의 결과를 생성하도록 하는 기법이다.

본 프로젝트에서는 다양한 상황을 고려하여 일반 입력, 다른 주제 입력, 모호한 입력의 총 3가지 예시를 설계하였다.

---

# Example 1 : 일반적인 입력

## 입력

```
영상 주제 : ChatGPT로 돈 버는 방법

타겟 시청자 : 20대 직장인

영상 길이 : 10분

핵심 메시지 : 현실적으로 가능한 AI 부업 소개
```

## 기대 출력

```
제목

"하루 30분 ChatGPT로 월 100만원 도전"

영상 구성

1. 후킹
2. 문제 제기
3. AI 부업 소개
4. 실전 예시
5. 마무리 및 CTA

썸네일

"AI가 대신 돈 벌어준다?"
```

---

# Example 2 : 다른 주제 입력

## 입력

```
영상 주제 : 아이폰 숨겨진 기능

타겟 : 아이폰 사용자

영상 길이 : 8분

핵심 메시지 : 잘 알려지지 않은 기능 소개
```

## 기대 출력

```
제목

"아이폰 유저 90%가 모르는 기능"

영상 구성

1. 후킹
2. 기능 소개
3. 사용 방법
4. 활용 팁
5. 마무리

썸네일

"이거 아직도 몰랐어?"
```

---

# Example 3 : 모호한 입력

## 입력

```
돈
```

## 기대 출력

```
입력 정보가 너무 광범위합니다.

아래 항목 중 하나를 선택해주세요.

- 부업
- 투자
- 절약
- 창업
```

모호한 입력에서는 LLM이 임의로 내용을 생성하지 않고 사용자에게 추가 정보를 요청하도록 설계하였다.

---

# Few-shot 적용 효과

Few-shot Prompt를 적용하면 다음과 같은 장점이 있다.

- 출력 형식이 일정하게 유지된다.
- 사용자 의도에 맞는 결과 생성 확률이 높아진다.
- 모호한 입력에서도 안정적으로 동작한다.
- Hallucination 발생 가능성을 줄일 수 있다.

---

# 결론

본 프로젝트는 3개의 Few-shot 예시를 활용하여 다양한 입력 상황에서도 일관된 결과를 생성하도록 설계하였다. 특히 모호한 입력에서는 추가 정보를 요청하는 방식으로 정확성과 신뢰성을 높였다.
