# 4. Hallucination 검증 및 Validation 설계

## 4.1 개요

LLM은 자연어 생성 능력이 뛰어나지만 존재하지 않는 정보나 잘못된 내용을 생성하는 Hallucination(환각) 문제가 발생할 수 있다.

본 프로젝트에서는 유튜브 콘텐츠 자동 생성 과정에서 발생할 수 있는 오류를 줄이기 위해 검증 기준과 처리 방식을 설계하였다.

---

# 4.2 Hallucination 발생 가능 상황

다음과 같은 상황에서 환각 발생 가능성이 높다.

| 상황 | 예시 |
|------|------|
| 존재하지 않는 정보 생성 | 실제 없는 기능이나 서비스 설명 |
| 확인되지 않은 통계 사용 | "사용자의 90%가 사용한다" |
| 최신 정보 오류 | 변경된 정책이나 가격 정보 |
| 출처 없는 사실 주장 | 근거 없는 전문가 의견 |

---

# 4.3 Hallucination 판단 기준

생성된 콘텐츠는 아래 기준으로 검증한다.

## 검증 기준 1 : 사실 확인 가능 여부

- 실제 존재하는 정보인지 확인
- 공식 자료 또는 신뢰 가능한 출처 확인

예시


잘못된 출력

"ChatGPT는 2026년부터 모든 기능을 무료 제공한다."

판정

→ 확인되지 않은 정보
→ Hallucination 가능성 높음


---

## 검증 기준 2 : 과도한 확정 표현 확인

확인되지 않은 내용을 확정적으로 표현하지 않는다.

주의 표현:

- 반드시 성공한다
- 100% 가능하다
- 누구나 돈을 벌 수 있다

수정 예시


수정 전

"AI를 사용하면 누구나 월 100만원을 벌 수 있다."

수정 후

"AI를 활용하면 추가적인 수익 활동을 시도할 수 있다."


---

## 검증 기준 3 : 숫자 및 통계 검증

숫자가 포함된 정보는 별도 확인한다.

검증 대상:

- 가격
- 사용자 수
- 성공률
- 수익 데이터
- 시장 규모

출처 확인이 어려운 경우:


[확인 필요]


표시한다.

---

# 4.4 Validation Process

전체 검증 과정은 다음과 같다.


LLM 결과 생성

    │
    ▼

사실성 검사

    │
    ▼

수치 검증

    │
    ▼

표현 강도 검사

    │
    ▼

수정 또는 [확인 필요] 표시

    │
    ▼

최종 출력


---

# 4.5 Prompt 기반 환각 방지 전략

System Prompt에 다음 제한 조건을 적용한다.


당신은 정확한 정보를 제공하는 콘텐츠 전문가입니다.

규칙:

확인되지 않은 사실을 생성하지 않는다.
존재하지 않는 데이터는 만들지 않는다.
불확실한 정보는 [확인 필요]로 표시한다.
추측과 사실을 구분한다.
과장된 표현을 사용하지 않는다.

---

# 4.6 검증 Example

## 입력


주제 : AI로 돈 버는 방법


## 잘못된 출력


AI를 이용하면 누구나 한 달 안에 월 500만원을 벌 수 있습니다.


## Validation 결과


문제점:

수익 보장 표현
근거 없는 숫자 사용

판정:

Hallucination 위험 있음


## 수정 출력


AI 도구를 활용하면 콘텐츠 제작,
자동화 업무 등 다양한 방식으로
생산성을 높이고 새로운 수익 기회를
찾을 수 있습니다.


---

# 4.7 최종 운영 기준

본 시스템은 다음 원칙을 유지한다.

- 정확하지 않은 정보는 생성하지 않는다.
- 확실하지 않은 내용은 표시한다.
- 사용자가 검증 가능한 형태로 제공한다.
- 품질보다 사실성을 우선한다.

---

# 결론

Hallucination Validation 시스템을 적용하여 LLM 생성 결과의 신뢰성을 높이고, 유튜브 콘텐츠 제작 과정에서 발생할 수 있는 잘못된 정보 생성을 최소화하도록 설계하였다.
