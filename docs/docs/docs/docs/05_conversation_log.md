# 5. LLM Conversation Log

## 5.1 개요

본 문서는 유튜브 콘텐츠 자동 생성 시스템 개발 과정에서 LLM과 주고받은 Prompt 및 결과 개선 과정을 기록한다.

단순한 결과 생성이 아닌 Prompt 수정과 검증 과정을 통해 출력 품질을 개선하였다.

---

# 5.2 Initial Prompt (초기 요청)

## User Prompt


AI를 활용해서 돈 버는 방법에 대한
유튜브 영상을 만들어줘.


---

## LLM Output


제목:
AI로 쉽게 돈 버는 방법

내용:
AI를 사용하면 누구나 쉽게 돈을 벌 수 있습니다.
ChatGPT를 활용하면 한 달에 500만원 이상도 가능합니다.


---

## 문제점 분석

초기 결과에서는 다음 문제가 발견되었다.

| 문제 | 내용 |
|---|---|
| 과장 표현 | 누구나 돈을 벌 수 있다고 표현 |
| 근거 부족 | 수익 관련 숫자 근거 없음 |
| 구조 부족 | 유튜브 영상 형식 부족 |

---

# 5.3 Prompt 개선

문제점을 해결하기 위해 System Prompt를 추가하였다.

## 개선 Prompt


당신은 유튜브 콘텐츠 전문가입니다.

조건:

1.사실 기반의 정보만 제공합니다.
2.확인되지 않은 수익 보장은 하지 않습니다.
3.영상 구조는 후킹 → 문제 제기 → 해결 방법 → 사례 → CTA순서로 작성합니다.
4.친근하지만 신뢰감 있는 말투를 사용합니다.

---

# 5.4 Improved Output

## LLM Output


제목:

AI로 시간을 절약하는 5가지 현실적인 방법

영상 구성:

1.AI 활용이 필요한 이유
2.업무 자동화 방법
3.콘텐츠 제작 활용법
4.실제 활용 사례
5.마무리 및 CTA

썸네일 문구:

"AI 때문에 일이 줄었다?"


---

# 5.5 결과 비교

| 항목 | 개선 전 | 개선 후 |
|---|---|---|
| 정확성 | 낮음 | 높음 |
| 구조화 | 부족 | 일정한 형식 유지 |
| 과장 표현 | 존재 | 제거 |
| 활용 가능성 | 낮음 | 높음 |

---

# 5.6 Prompt 개선 효과

Prompt Engineering 적용 후 다음 효과를 확인하였다.

- 출력 형식 일관성 향상
- Hallucination 감소
- 사용자 요구사항 반영 증가
- 콘텐츠 제작 과정 자동화 가능

---

# 결론

본 Conversation Log를 통해 LLM 결과를 그대로 사용하는 것이 아니라 Prompt 설계와 검증 과정을 통해 지속적으로 개선하는 방식을 적용하였다.
