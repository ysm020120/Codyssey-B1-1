# 2. 시스템 설계 문서

## 2.1 프로젝트 개요

본 시스템은 LLM을 활용하여 유튜브 콘텐츠 제작 과정을 자동화하기 위해 설계되었다.

사용자가 영상 주제만 입력하면 다음 순서대로 결과를 생성한다.

1. 영상 아이디어 기획
2. 대본 생성
3. 제목 생성
4. 썸네일 문구 생성
5. 최종 결과 검토

---

# 2.2 전체 시스템 구조

```
사용자 입력
      │
      ▼
입력 템플릿 생성
      │
      ▼
System Prompt 적용
      │
      ▼
User Prompt 적용
      │
      ▼
LLM 실행
      │
      ▼
결과 검증
      │
      ▼
최종 출력
```

---

# 2.3 업무 과업 입력 템플릿

사용자는 아래 형식으로 정보를 입력한다.

| 입력 항목 | 설명 |
|-----------|------|
| 영상 주제 | 제작할 영상의 핵심 키워드 |
| 타겟 시청자 | 연령, 관심사 등 |
| 영상 길이 | 예: 10분 |
| 핵심 메시지 | 전달하고 싶은 내용 |
| 원하는 톤 | 친근함, 전문가, 유머 등 |

### 입력 예시

```
영상 주제 : ChatGPT로 돈 버는 방법
타겟 : 20대 직장인
영상 길이 : 10분
핵심 메시지 : AI를 활용한 현실적인 부업
톤 : 친근한 말투
```

---

# 2.4 Prompt 구조

Prompt는 역할별로 분리하여 설계하였다.

## ① System Prompt

LLM의 역할과 제약 조건을 정의한다.

예시

- 유튜브 콘텐츠 전문가 역할 수행
- 허위 사실 생성 금지
- Markdown 형식 유지
- 친근한 말투 사용

---

## ② User Prompt

사용자의 입력을 전달한다.

예시

```
주제 : ChatGPT로 돈 버는 방법

10분 분량으로 작성해주세요.
```

---

# 2.5 Prompt 분리 이유

Prompt를 역할별로 분리하면 다음과 같은 장점이 있다.

- 재사용 가능
- 유지보수 용이
- Prompt 수정 비용 감소
- 여러 프로젝트에 쉽게 적용 가능

---

# 2.6 출력 구조

LLM은 항상 동일한 형식으로 출력하도록 설계하였다.

```
1. 제목

2. 영상 소개

3. 대본

4. CTA

5. 썸네일 문구
```

---

# 2.7 Guardrail(환각 방지)

다음 규칙을 적용하였다.

- 존재하지 않는 사실 생성 금지
- 확인되지 않은 수치는 생성하지 않음
- 정책 변경 사항은 추측하지 않음
- 출처가 없는 정보는 **[확인 필요]**로 표시

---

# 2.8 비용 절감 전략

비용 절감을 위해 Hybrid 구조를 적용하였다.

| 단계 | 사용 모델 |
|------|-----------|
| 아이디어 브레인스토밍 | Gemini 1.5 Pro |
| 대본 생성 | Claude 3.5 Sonnet |
| 검토 및 보완 | GPT-4o |

이를 통해 비용과 품질의 균형을 맞추도록 설계하였다.

---

# 2.9 Context Compression

긴 대화에서는 이전 내용을 요약하여 유지한다.

예시

```
Session Summary

- 영상 주제 : AI 부업
- 대상 : 20대
- 영상 길이 : 10분
- SEO 적용 완료
```

이를 통해 입력 토큰 수를 줄이고 응답 속도를 향상시킨다.

---

# 2.10 기대 효과

본 시스템을 적용하면 다음과 같은 효과를 기대할 수 있다.

- 콘텐츠 제작 시간 단축
- 일정한 결과물 품질 유지
- 프롬프트 재사용성 향상
- 운영 비용 절감
- Hallucination 감소
