# 1. LLM 모델 비교·선정 보고서

## 1.1 프로젝트 개요

### 프로젝트 목적

본 프로젝트는 대규모 언어 모델(LLM)을 활용하여 유튜브 콘텐츠 제작 과정을 자동화하는 것을 목표로 한다.

사용자는 영상의 주제만 입력하면 다음 과정을 자동으로 수행할 수 있다.

- 영상 아이디어 기획
- 영상 구성 작성
- 대본 생성
- 제목 추천
- 썸네일 문구 생성

최종적으로 콘텐츠 제작 시간을 단축하고 일정한 품질의 결과물을 생성하는 것을 목표로 한다.

---

# 1.2 비교 대상 모델

본 프로젝트에서는 아래 3개의 LLM을 비교하였다.

| 모델 | 개발사 | 주요 특징 |
|------|---------|----------------|
| GPT-4o | OpenAI | 높은 지시사항 준수율과 안정적인 추론 능력 |
| Claude 3.5 Sonnet | Anthropic | 긴 문맥 유지와 자연스러운 한국어 표현 |
| Gemini 1.5 Pro | Google | 빠른 응답속도와 대용량 Context 지원 |

---

# 1.3 평가 기준

모델 비교는 다음 4가지 기준으로 진행하였다.

## (1) 창의성

유튜브 콘텐츠 특성상 흥미를 유발하는 제목과 대본을 생성하는 능력을 평가하였다.

평가 요소

- 후킹(Hooking)
- 자연스러운 말투
- 제목의 클릭 유도력

---

## (2) 지시사항 준수율

Prompt에서 요구한 조건을 얼마나 정확하게 수행하는지를 평가하였다.

평가 요소

- 글자 수
- 출력 형식
- Markdown 구조
- XML 태그 유지
- JSON 형식 유지

---

## (3) Hallucination 발생 여부

존재하지 않는 정보를 생성하는 빈도를 평가하였다.

평가 요소

- 허위 기능 생성
- 존재하지 않는 수치 생성
- 잘못된 정책 안내
- 허위 출처 생성

---

## (4) 장문 Context 유지

10Turn 이상의 대화에서 초기 Prompt를 얼마나 유지하는지 평가하였다.

평가 요소

- 초기 설정 유지
- 등장인물 유지
- 스타일 유지
- 이전 대화 기억

---

# 1.6 정량 평가

평가 점수는 아래 기준으로 산정하였다.

| 항목 | 가중치 |
|------|--------|
| 창의성 | 30% |
| 지시사항 준수 | 30% |
| Hallucination 억제 | 20% |
| Context 유지 | 20% |

총점 계산식

```
총점 = (창의성 ×0.3)
      +(지시사항×0.3)
      +(Hallucination×0.2)
      +(Context×0.2)
```

# 1.8 선정 결과

최종 선정 모델은 **Claude 3.5 Sonnet**이다.

선정 이유는 다음과 같다.

- 가장 자연스러운 한국어 표현
- 긴 문맥 유지 성능 우수
- Hallucination 발생 빈도가 가장 낮음
- Prompt를 안정적으로 수행

# 1.9 결론

본 프로젝트에서는 세 가지 LLM을 동일한 조건에서 비교하였다.

평가 결과 Claude 3.5 Sonnet이 가장 우수한 성능을 보였으며, 최종 콘텐츠 생성 모델로 선정하였다.

Gemini 1.5 Pro는 아이디어 브레인스토밍 단계에 활용하고, GPT-4o는 구조화 및 검증 단계에 활용하는 Hybrid 전략을 적용하여 비용 절감과 품질 향상을 동시에 달성하도록 설계하였다.
